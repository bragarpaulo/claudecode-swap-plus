Swap Plus

Desligado, o Swap Plus não fala com o servidor e não mexe no login: o Claude Code fica com o acesso que tem agora. Ligado, ele recebe do servidor a conta escolhida para este computador e envia ao servidor todo login novo que você fizer no Claude Code (só nos computadores do administrador).

Servidor

O login de cada conta só vale para quem renovou por último. Por isso só o servidor guarda e renova os logins, e cada computador recebe apenas o acesso da conta que o servidor escolheu para ele. As regras de troca e os ajustes de cada conta ficam no servidor e valem para todos; os avisos e a exibição continuam sendo de cada computador.

Troca automática

Quem decide é o servidor, olhando o uso de todas as contas e quais computadores estão usando cada uma. Este computador recebe a conta nova em até 30 s e o Claude Code aberto passa a usá-la sozinho. Ligar ou desligar aqui vale para todos os computadores conectados.

Alterações não salvas

Para cada limite: quando a conta ativa chegar em X%, avisar e/ou trocar de conta. A barrinha mostra o uso atual da conta ativa e onde estão as linhas. As regras valem depois de clicar em “Salvar regras”.

As linhas de troca e a estratégia ficam no servidor e valem para todos os computadores conectados. As linhas de aviso são só deste computador.

Contas

Mudanças aqui valem na hora, no servidor, para todos os computadores. Usar regra padrão: desmarque para dar à conta linhas de troca só dela — sessão de 5h, semanal e modelo (ex.: 70% na sessão para guardar folga). Prioridade só vale na estratégia “Por prioridade”.
