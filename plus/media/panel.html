    O aviso aparece neste VS Code quando a conta em uso aqui passa do percentual. Ele só avisa: quem troca de conta sozinho é o servidor, pelas regras do painel do Swap.

    Depois da troca de conta

    Quando uma conversa do Claude Code para com “You've hit your limit” e o Swap Plus troca de conta, ele manda nela a mensagem “Troquei de conta, pode continuar.” e ela segue sozinha. Vale para todas as janelas do VS Code deste computador. Para isso o Swap Plus põe um gancho (StopFailure) no settings.json do Claude Code.

    Exibição

    Vale para a barra de baixo, a lista de contas, esta tela e os avisos do Swap Plus. Não é uma trava: o próprio Claude Code continua mostrando o e-mail da conta.

    Atualizações da extensão

    Contas, regras de troca, usuários e os outros serviços ficam no painel do Swap.

    Só o administrador entra no painel.
