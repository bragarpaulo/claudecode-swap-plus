    Como ler a lista

    Cada conta é uma linha. Clique nela para abrir o cartão com todos os limites, os dados e os ajustes; clique de novo para fechar. A linha mostra uma barra só, a do limite mais perto de parar a conta (o de maior porcentagem entre sessão de 5 horas, semanal e modelo), quando ele renova e se a conta participa da troca.

    As contas em uso (com computador nelas agora) aparecem primeiro. Depois vêm as outras que participam da troca, na ordem da fila: primeiro a conta cujo limite semanal renova antes; em empate, a menos usada. As que não participam ficam no grupo “Fora da troca”, embaixo.

    As barras mostram quanto de cada limite já foi usado; o tracinho é a linha de troca. Verde: longe da linha. Amarelo: chegando perto. Vermelho: na linha (o servidor passa o computador para outra conta).

    “Acesso” é a chave de poucas horas que o servidor renova sozinho. “Login” é o que permite renovar: quando vence, é preciso entrar de novo com a conta. Faltando menos de 3 dias, a linha da conta pisca “Fazer login até…” com a data e a hora.

    Regras de troca

    Valem para todos os computadores. A troca automática liga e desliga na hora; as outras regras só mudam quando você clicar em “Salvar regras”.

    As regras foram mudadas em outro lugar enquanto você editava. “Desfazer” carrega as regras novas.

    Troca automática

    Desligada, nenhum computador troca de conta sozinho. A troca manual (em Serviços) continua funcionando.

    Computadores

    Vale para os computadores em uso agora. Um computador só usa contas liberadas para ele (“Computadores permitidos”, no cartão da conta): se não puder usar a conta dos outros, fica na melhor conta liberada para ele.

    Quando trocar de conta

    Quando a conta em uso num computador chegar nesta porcentagem, o servidor passa esse computador para outra conta com folga.

    Padrão: 90%. Cada conta pode ter uma linha própria (no cartão da conta, em “Ajustes desta conta”).
    Padrão: 80%.
    Padrão: 95%. Com “Trocar de conta” (abaixo), é onde o servidor troca a conta; com “Seguir na mesma conta”, é onde as conversas novas passam para o Opus 5.5.

    Ajustes finos
    h Só na estratégia “Aproveitar ao máximo”: troca antes da linha para uma conta cuja cota semanal zera dentro deste tempo e ainda tem pelo menos 20% sobrando. De 1 a 168 horas. Padrão: 24.
    min Vale para as trocas antecipadas. Quando a conta chega numa linha de troca, troca na hora. De 0 a 240 minutos. Padrão: 5.
    pontos A conta para onde vai precisa estar pelo menos isso abaixo de cada linha. Evita trocar para uma conta que logo precisaria trocar de novo. De 0 a 30. Padrão: 5.

    Conectar um computador

    1. No computador, abra o VS Code com a extensão Swap Plus instalada.
    2. Abra a tela do Swap Plus (comando “Swap Plus: Configurar trocas automáticas”) e, no cartão “Servidor”, clique em Entrar com Google.
    3. O navegador abre: entre com a conta do administrador ou com um dos usuários liberados em Usuários.
    4. Pronto. O computador aparece nesta lista e já recebe uma conta.

    O login com Google está desligado no servidor. Por enquanto, conecte usando o código de conexão abaixo.

    Sem Google: código de conexão

    Gere um código e cole no VS Code em “Colar código” (no mesmo cartão “Servidor”). Vale 10 minutos e uma vez só.

    Recuperação

    O kit de recuperação tem a chave mestra do cofre e a senha do backup. Guarde estas duas chaves FORA deste servidor (gerenciador de senhas ou um arquivo no seu computador). Se o servidor for perdido, só com elas o backup abre.

    Por segurança, o kit só aparece até 15 minutos depois de entrar com o Google. Entre de novo para ver.
